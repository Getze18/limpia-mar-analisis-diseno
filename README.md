# Limpia-Mar

Videojuego 2D de laberinto con vista desde arriba. El jugador controla a **Aspi**, una pequeña aspiradora submarina que recorre los pasillos de un arrecife lleno de basura. Cada basura que aspira suma puntos; pero en el arrecife también nadan peces, y si Aspi se traga uno pierde muchos puntos. El nivel se gana al limpiar toda la basura antes de que se acabe el tiempo. El juego tiene 5 niveles, cada uno con laberintos más grandes y más peces.

**Mensaje del juego:** la basura en el mar daña a los animales; limpiar con cuidado también es cuidar la vida marina.
